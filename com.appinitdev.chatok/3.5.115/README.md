## En pocas palabras

ChatOk reúne conversaciones privadas y envío de archivos en una aplicación de mensajería. Según su ficha actual, permite utilizar una identidad propia de la aplicación sin vincular un número de teléfono ni una dirección de correo electrónico.

## Funcionalidades destacadas

- Intercambiar mensajes y archivos con tus contactos.
- Enviar fotografías con visualización única.
- Proteger la apertura de la aplicación con PIN o autenticación biométrica compatible.
- Elegir entre distintos temas para la interfaz.
- Utilizar una frase de recuperación para gestionar el acceso a la cuenta.
